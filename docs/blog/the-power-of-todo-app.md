Building a todo app is the classic test for javascript frameworks: https://todomvc.com. It's like a simple but also has enough state machinery, you can show a framework can handle client side reactivity with little code.

AppWeaver todo app is not client side, therefore we don't care about the javascript framework used. I didn't started it to showcase what appweaver can do either, it was born out of necessity.

To be frank a regular markdown file is enough for the most part, and todo app is very close to it. In fact you can view todo app as a markdown list too, in text mode or if you click the copy button on the widget header.

One downside of markdown files is you can't easily edit them in your phone without the keyboard. You have to rely on the AI to edit it for you. I didn't like that beacuse why do I use AI if I know what to do exactly with this simple list.

So I started to develop and use it actively while working on AppWeaver to this day. I'm still using it everyday and trying to make it better because I genuinely need it. I got 96 active items on my plate (228 including done items) just for developing AppWeaver. It's very useful to me and I believe it would be to others too.

What else I provide with todo app:

AI modifications are still possible -maybe you want to mass edit it-, but with using drafts. AI can manipulate the items through creating drafts that you can review and even revise them over and over until you are satisfied with them.

Focus mode: You have a lot of items but you want to focus on a specific branch of the tree.

Prioritization: It's hard understand which item is the most important one, especially when it's deep in the tree. App helps you define "champions" within each branch, and let you do a tournament styles match session between them to have a clear "winner" 🏆.

Use the checkmark toolbar button to filter items by their status. You can find the item you accidentally marked it as done and bring back, or maybe you want to see your achievements. Or sometimes just want to see what you are working at the moment by filtering only "In Progress" items. Very basic stuff but increase the usability by a lot.

Easily expand, collapse all items. Another little utility from the toolbar. Also check the filter when you need to find a specific item.
